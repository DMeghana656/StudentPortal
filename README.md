# StudentPortal

A full-stack **Student Internship & Skill Tracking Portal** developed using React, Node.js, Express.js, and MySQL.

StudentPortal helps students manage their internship applications, skills, certificates, and related academic information through a centralized web application.

## Features

* Student management
* Company management
* Internship management
* Internship application tracking
* Skill management
* Certificate management
* Student-skill mapping
* Dashboard for viewing portal information
* MySQL database integration
* REST API using Node.js and Express.js
* React-based frontend

## Main Modules

### Students

Manage student information such as name, email, and department.

### Companies

Store company information and available internship opportunities.

### Internships

Manage internship positions offered by companies.

### Applications

Track student applications and their application status.

### Skills

Maintain a list of technical and professional skills.

### Certificates

Store certificates earned by students.

### Student Skills

Connect students with the skills they possess.

## Project Objectives

* Provide a centralized internship management system.
* Help students track internship applications.
* Maintain student skill information.
* Store certificates digitally.
* Provide a structured database for internship-related information.
* Demonstrate full-stack web development using React, Node.js, Express.js, and MySQL.
